# Fotos einfügen

Lege eine Datei mit exakt einem dieser Namen hier ab — sie ersetzt den
Platzhalter auf der Website automatisch, ohne Codeänderung:

| Datei              | Wo sie erscheint                              | Format               |
| ------------------ | ---------------------------------------------- | -------------------- |
| `hero.jpg`          | Startseite, direkt unter den Buttons            | quer, 16:9           |
| `gallery-1.jpg`     | Startseite, „Impressionen“, erstes Bild         | quadratisch, 1:1     |
| `gallery-2.jpg`     | Startseite, „Impressionen“, zweites Bild        | quadratisch, 1:1     |
| `gallery-3.jpg`     | Startseite, „Impressionen“, drittes Bild        | quadratisch, 1:1     |
| `slow-running.jpg`  | „Was ist Slow Running?“-Seite                   | quer, 16:9           |
| `neu-hier.jpg`      | „Neu hier?“-Seite                               | quer, 16:9           |

Weitere Slots (Namen, Alt-Text, Bildunterschrift) stehen in
`src/photos.js`.
